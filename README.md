# Secure Login System

A secure Flask-based login system built using Python.

## Features

- User registration and login
- Password hashing using Bcrypt
- Password validation
- CSRF protection
- Secure session management
- Login attempt lockout
- SQLite database
- Environment variables for secret key

## Technologies Used

- Python
- Flask
- Flask-Bcrypt
- Flask-WTF
- SQLite
- HTML
- CSS
